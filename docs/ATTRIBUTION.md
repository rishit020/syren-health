# Luvia source attribution and scope

This is a local single-project reconstruction of **Luvia**, created by **Shaigexp**. The current website adapts the template for Syren Health, preserving its core design system and motion.

- Preview: https://luvia.framer.website/
- Official listing: https://www.framer.com/marketplace/templates/luvia/
- Official free remix: https://framer.link/r03V4Fl?duplicateType=siteTemplate

The listing identifies Luvia as free content. The license permits using and modifying free content in an own project, including commercial work. Ownership stays with the creator. This repository is not offered as a standalone template, competing marketplace item, or reusable asset package. Do not distribute it as one.

The official remix link leads to a Framer login in the available session; no authorized editor project was accessible. Publicly rendered template markup, styles, content, fonts, images, SVG artwork and videos were therefore inspected. Assets preserve their original provenance in reference/asset-manifest.json. The implementation does not copy or require Framer's application/runtime JavaScript. The active site uses Syren Health branding, supplied product renders and illustrative generated photography. Historical source captures are retained for provenance.

REA is MIT licensed; its installed CLI is used as an inspection tool, not copied into this application. React, Vite, Playwright, Pixelmatch, PNGJS and Cheerio retain their respective package licenses in node_modules. No third-party source code was adapted from an unrelated site.

Asset rights are recorded from the free template's distribution, not inferred from the mere fact that an asset URL is public. Before publishing a later customized product, retain any notices and review the license conditions for its particular end use.
